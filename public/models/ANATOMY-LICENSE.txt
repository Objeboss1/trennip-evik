The file used here is the Draco-compressed anatomy.glb built by the
free-muscles project (https://github.com/tiralonghipol/free-muscles,
copyright tiralonghipol). That project extracted muscles and bones, removed
connective tissue, decimated the mesh, added muscle-group metadata and
compressed the file with Draco.
